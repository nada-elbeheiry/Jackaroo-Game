# Jackaroo Board Game

## Description
This is a Java-based implementation of the Jackaroo board game developed as part of a university project with three other colleagues.

## Features
- Multiplayer gameplay
- Turn-based logic
- Game rule enforcement

## Technologies
- Java
- JavaFX

## My Contribution
- Implemented backend game logic
- Developed player interaction and turn handling
- Contributed to GUI implementation

## Notes
The GUI is partially implemented. The main focus of the project was backend logic.
